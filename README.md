# Week 1 Assessment

## Project Overview
This project analyses employee data using Python, NumPy, Pandas, and Matplotlib.

## Setup Steps
1. Install Python.
2. Install the required packages: `pip install numpy pandas matplotlib notebook nbconvert`.
3. Open the project in VS Code.
4. Run the Python analysis script.
5. Open the Jupyter notebook and run its cells.

## Findings Summary
1. The dataset contains 8 employee records.
2. Salaries vary across employees.
3. Chennai employee records can be identified.
4. Average salaries can be calculated by department.
5. A bar chart compares department-wise average salaries.
